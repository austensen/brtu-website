# Code of conduct

We want everyone who interacts with this project—whether in issues, pull requests, discussions, or chat—to have a constructive, respectful experience.

## Our standards

- **Be respectful.** Disagree on ideas, not people. Assume good intent where reasonable.
- **Be inclusive.** Welcome newcomers; avoid jargon without explanation when it would exclude others.
- **No harassment.** Do not target anyone with abuse, slurs, sexual attention, threats, or sustained disruption.
- **Keep it relevant.** Stay on topic in threads; use the right channels for support versus feature discussion when the project provides them.

## Scope

This applies to all project spaces (repository, issue trackers, pull requests, and official community channels tied to the project).

## Reporting

If you see behavior that violates this code of conduct, please report it to the project maintainers (for example via a private message on the platform hosting this repository, or by opening a confidential issue if your host supports it). Maintainers will review reports in good faith and may warn, moderate, or remove participants when needed to keep the community healthy.

## Attribution

This is a short, project-local code of conduct inspired by common open-source community norms. It is not a legal document; it expresses expectations for collaboration on this repository.
